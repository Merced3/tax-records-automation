# For the Tax Professional

This folder contains tax-related documents and notes, organized by year,
written for human review by a tax professional.

## Purpose

The goal of this material is to gather everything needed to:

- identify which years were filed and which were not
- reconstruct income, deductions, and supporting records
- make it easier for a tax professional to review the situation quickly
- reduce missing information and confusion before professional help is involved

## Current overall status

- IRS transcripts were pulled first to establish the baseline
- The IRS records indicate that the last filed return was **2021**
- Years **2022, 2023, and 2024** appear unfiled based on the lack of return transcripts and the presence of non-filing letters
- **2025** is the current filing-season year and is still being assembled
- Earlier years (**2019–2021**) are included mainly for context and supporting background records
- Detailed yearly summaries begin in **2022** because that is where the current catch-up project starts and where the missing-return problem begins

## How the records are organized

Documents live in `records/<year>/` (not committed to git). Each yearly
folder contains some combination of:

- IRS docs
- bank statements
- brokerage records
- gig-platform tax documents
- mileage/expense exports
- yearly summary notes
- any unusual supporting material relevant to that year

## What each yearly summary is for

Each `20XX SUMMARY.txt` file acts like a year-level readme. It explains:

- whether the year appears filed or unfiled
- what income sources are known
- what work/activity happened that year
- what documents are already collected
- what gaps or weird situations still exist
- what a tax professional should pay attention to first

## Why there are detailed summaries only from 2022 forward

- **2021** appears to be the last year that was filed
- **2022 onward** is the active cleanup range for delinquent / incomplete tax work
- Older years are kept mainly for reference, context, and brokerage history
- The later the year, the more complete the records usually are
- 2022 still has missing mileage/expense support, but it is the first year that clearly needs reconstruction work

## Important notes about the data

- IRS transcripts are the starting skeleton, not the full story
- Bank statements, platform summaries, and brokerage records are used as backup/supporting evidence
- Everlance mileage/trip data is useful in later years, but some revenue/transaction totals appear distorted by transfers or categorization issues
- Venmo and Cash App records appear mostly personal reimbursement-related unless noted otherwise in a yearly summary
- Some years include unusual issues that need professional review, especially 2023

## Recommended review order for a tax professional

1. Read this file
2. Read `questions-for-pro.txt`
3. Review `2022 SUMMARY.txt`
4. Review `2023 SUMMARY.txt`
5. Review `2024 SUMMARY.txt`
6. Review `2025 SUMMARY.txt`
7. Open the supporting documents inside each year folder as needed

## Main objective

Build a clean, honest, organized case file for each year so a professional can determine:

- what must be filed
- what can be reconstructed
- what deductions are supportable
- what risks or missing pieces still need attention
